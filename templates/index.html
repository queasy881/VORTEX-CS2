What it does

One script. No IDE needed. Just talk and it builds.

📁

Creates files & folders

Generates entire project structures — directories, source files, configs — from a single prompt.

✏️

Edits existing code

Reads your files, understands the context, and makes precise edits with find-and-replace.

⚡

Runs commands

Installs packages, runs scripts, executes git commands — all without leaving the conversation.

🔗

Chains operations

Doesn't stop after one tool call. It keeps going until the full task is done — create, edit, test, fix.

🧠

Remembers context

Full conversation history. Ask follow-ups, iterate on code, build incrementally across turns.

💰

Dirt cheap

DeepSeek API is a fraction of the cost of OpenAI/Anthropic. Build all day for pennies.

Get started in 60 seconds

Download

Grab the .py file from this page or clone the repo.

Get API key

Sign up at platform.deepseek.com and grab your key.

Set the key

Paste it into the script or set DEEPSEEK_API_KEY env var.

Run it

python deepseek_code.py
